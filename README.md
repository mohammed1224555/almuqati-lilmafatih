### عن المشروع
موقع احترافي كامل لمتجر **المقاطي للمفاتيح** في الدمام والمنطقة الشرقية، متخصص في:
- نسخ مفاتيح البيوت والسيارات
- برمجة المفاتيح الإلكترونية والريموت
- مفاتيح ليزر (Tibbe - Simplex)
- خدمة 24 ساعة

### المميزات
- تصميم عربي كامل (RTL) + دعم الوضع الليلي
- SEO محسن (meta tags + Schema.org)
- تصميم عصري ومتجاوب مع جميع الأجهزة
- أقسام: الرئيسية، الخدمات، الأسعار، آراء العملاء، التواصل

### التقنيات المستخدمة
- HTML5
- CSS3 (Custom Properties + Neumorphism)
- JavaScript
- Google Fonts (Cairo + IBM Plex Sans Arabic)
